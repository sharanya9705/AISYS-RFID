# Production Readiness Backlog

## 1. Current status
The project is a valid prototype demonstrating the key AISYS workflows and acceptance scenarios. It is not yet a complete production-ready package under the full SOP.

## 2. Outstanding work
- formal D1 to D9 documentation package
- automation for offline deployment and update package
- versioned migration framework and rollback automation
- service packaging for Windows operations
- secure secret management and least-privilege controls
- more complete role and user administration tools
- pilot testing and UAT evidence with real user scenarios
- full license tracking and internal governance review

## 3. Priority backlog
1. Build a real installer package and rollback mechanism.
2. Implement formal migration versioning and restore automation.
3. Add stronger admin configuration and access logging.
4. Expand docs for user training and troubleshooting.
5. Validate against a realistic Windows server deployment checklist.

## 4. Exit criteria for full compliance
The project can be considered close to SOP compliance when it includes:
- complete architecture and deployment documents
- tested migration rollback and restore processes
- sealed version-controlled release package
- evidence of update and rollback in a staged environment
- admin and user documentation signed off by stakeholders
